# Выпуск и передача

## Выполнить перед релизом

1. `npm ci && npm run check`.
2. `npx playwright install chromium && npm run test:e2e`.
3. `npm run preview` и проверить production-страницу.
4. На целевых устройствах проверить Chrome, Safari и Firefox с аппаратным WebGL2: обе комнаты, четыре бренда, оба характера, 16:9/9:16/1:1/4:5, лучи, проход света, PNG 4K, импорт JSON прототипа. Автоматизированные проверки выполняются в Chromium; остальные браузеры требуют отдельной проверки.
5. Для видео проверить поддерживаемый контейнер/кодек и плавность на целевой машине. 60 fps — запрос MediaRecorder, не гарантия offline-энкодинга. Декодируемость, размер и длительность проверяются автоматизированно в Chromium.
6. Сверить результат с гайдом в Figma (кадры в `docs/figma/`) и с владельцем бренд-гайда. Для правок калибровки — `tools/shoot.mjs`.
7. Разместить `dist` или собрать Docker-образ. Проверить CSP, отдачу шрифтов/шейдеров, экспорт и перезагрузку по production URL. В репозитории есть nginx-конфигурация; фактическая публикация требует выбора хостинга.

## Данные

Проект не отправляет сцены на сервер. Хранятся только в localStorage текущего origin. Автосохранение не заменяет проектный файл: JSON нужен для переноса между устройствами и долгосрочного хранения. Очистка данных браузера удаляет локальную сессию. Серверных секретов и пользовательских API-ключей нет.

## Практические ограничения

- WebGL2 и рендер в RGBA16F обязательны. Для неподдерживаемого GPU есть сообщение, но нет упрощённого Canvas-рендерера.
- Ограничение изображения — 4096 px на сторону и аппаратные лимиты. В 4K тяжёлый объём может на время занять основной поток ожиданием GPU.
- SVG и настоящая прозрачная HDR-композиция не поддерживаются.
- Видео ограничено Full HD и реальным временем; слабые GPU могут пропускать кадры.
- WebGL-ядро, модель и UI проходят strict TypeScript. GLSL компилируется драйвером в браузере; регрессии проверяются через реальный GPU-проход и экспорт.
