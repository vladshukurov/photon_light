# Фотон — студия света VK

Генератор световых сцен и фонов для айдентики VK: макеты, веб, моушн. Один белый источник светит вскользь по стене сквозь дымку; бренд проявляется через цвет стены и среды, а не через окраску света. Работает в браузере, без сервера и учётных записей.

## Запуск

Node.js 22.12+ (рекомендуется 24).

```sh
npm ci
npm run dev
```

Нужен браузер с WebGL2 и `EXT_color_buffer_float` (Chrome, Safari 17+, Firefox с аппаратным ускорением).

## Что умеет

- **Один свет на все направления.** Источник — угол вокруг кадра и отступ от края. Шесть направлений гайда — точки на этой оси, а не шесть разных пресетов. Свет двигают мышью прямо на холсте или по миниатюре в панели; клавиши 1–6 ставят направления гайда.
- **Луч прожектора, как на съёмке:** почти белая лампа далеко за краем светит вдоль стены узким конусом — свет входит в кадр клином и гаснет к надписи. Второй источник — отлив, её свет, отражённый цветной стеной. Источник не читается: горячего пятна нет.
- **Бренды:** у VK две версии — ч/б и с лёгким синим отливом; у Музыки, Видео и Доната отлив в светлый акцент гайда (`docs/figma/`). Цвет живёт в спаде и в воздухе, а не в пятне.
- **Надпись в свете:** как в баннерах из макета — VK Sans Display Condensed Medium с трекингом −4%, резкие белые буквы поверх их копии с прогрессивным размытием: тонкий ореол со стороны источника, к дальнему краю буквы резкие. Направление берётся из положения света и перестраивается само.
- **Комнаты:** тёмная и светлая. Неосвещённая стена светлой комнаты выходит ровно #C7CBD6.
- **Выразительность:** 0% — калибровка по кадрам гайда «Свечение. Направления» и рефам арт-директора (`docs/references/ad-*`); 100% — тот же свет ярче и объёмнее, с сильным ореолом. Между ними — плавный переход.
- **Мягкие лучи:** структура света с неровным шагом, расплывается к концу луча.
- **Моушн пока скрыт.** Проход света и запись видео есть в модели и движке (`angleAt`, `exportVideo`), но в интерфейсе выключены до проработки моушена.
- **Форматы:** 16:9, 9:16, 1:1, 4:5. При смене формата свет остаётся на том же месте относительно краёв.
- **Экспорт:** PNG/JPG до 4096 px отдельным проходом в полном разрешении, копирование PNG в буфер для вставки в Figma; три слоя (фон, свет, объём) — каждый копируется или скачивается отдельно, режим Plus lighter.
- **JSON-пресет:** сохранение, открытие, перетаскивание на окно. Пресеты прототипа с 58 ключами переносятся в новую модель автоматически.
- **Работа без потерь:** отмена/повтор на 80 шагов, автосохранение в браузере.

## Проверки

```sh
npm run check            # ESLint, TypeScript, сборка, unit-тесты
npx playwright install chromium
npm run test:e2e         # реальный WebGL: редактор, экспорт, импорт, мобильная вёрстка
```

## Калибровка света

`tools/sheet.html` рендерит набор Look в один контактный лист рядом с эталонами. `tools/shoot.mjs` снимает его в PNG с аппаратным GPU — так проверяются правки шейдера и профилей:

```sh
npm run dev
node tools/shoot.mjs '{"cell":[589,310],"cols":2,"refs":["/docs/references/ad-setup-top.png"],"looks":[{"angle":0,"tone":"blue"}]}' sheet.png
```

Каждому Look в листе можно передать `mode` (`light`, `haze`, `base`), чтобы снять слой отдельно. Рефы арт-директора лежат в `docs/references/ad-*`.

## Развёртывание

Продакшен: https://photon-light.vercel.app — Vercel, настройки в `vercel.json` (сборка Vite, заголовки безопасности и кеширование ассетов). Новая версия: `npx vercel deploy --prod`.

```sh
npm run build   # содержимое dist/ — на любой статический HTTPS-хостинг
docker build -t photon-studio . && docker run --rm -p 8080:8080 photon-studio
```

`deploy/nginx.conf` — gzip, CSP и кеширование хешированных ассетов.

## Устройство

```text
src/
  domain/      модель Look, бренды, сцена из Look, тон-кривая, история
  engine/      WebGL2: сцена (light.frag), накопление, bloom, ACES, экспорт
  components/  холст, инспектор, миниатюра источника, экспорт
  hooks/       состояние Look с историей и автосохранением
tools/         контактный лист для калибровки
docs/          архитектура, гайд из Figma, эталоны
```

Подробнее — [архитектура](docs/architecture.md), [выпуск](docs/release.md).
