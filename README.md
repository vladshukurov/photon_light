# Свет — студия света VK

Генератор световых сцен и фонов для айдентики VK: макеты, веб, моушн. Один белый источник светит вскользь по стене сквозь дымку; бренд проявляется через цвет стены и среды, а не через окраску света. Работает в браузере, без сервера и учётных записей.

## Запуск

Node.js 22.12+ (рекомендуется 24).

```sh
npm ci
npm run dev
```

Нужен браузер с WebGL2 и `EXT_color_buffer_float` (Chrome, Safari 17+, Firefox с аппаратным ускорением).

## Что умеет

- **Один свет на все направления.** Источник — угол вокруг кадра и отступ от края. Шесть направлений гайда — точки на этой оси, а не шесть разных пресетов. Свет двигают мышью прямо на холсте или по миниатюре в панели; клавиши 1–6 ставят направления гайда.
- **Луч прожектора, как на съёмке:** почти белая лампа далеко за краем светит вдоль стены узким конусом — свет входит в кадр клином и гаснет к надписи. Второй источник — отлив, её свет, отражённый цветной стеной. Источник не читается: горячего пятна нет.
- **Бренды:** у VK две версии — с лёгким синим отливом (по умолчанию) и ч/б; у Музыки, Видео и Доната отлив в светлый акцент гайда (`docs/figma/`). Цвет живёт в спаде и в воздухе, а не в пятне.
- **Рассеивание VK:** ч/б и синий отлив используют одну форму и яркость луча. Ползунок «Рассеивание» добавляет широкий мягкий ореол независимо от цвета; 0% сохраняет собранный луч, 100% даёт широкое свечение. Настройка хранится в JSON и автосохранении.
- **Надпись в свете** (пока скрыта: `LETTERING` в `look.ts`): как в баннерах из макета — VK Sans Display Condensed Medium с трекингом −4%, резкие белые буквы поверх их копии с прогрессивным размытием: тонкий ореол со стороны источника, к дальнему краю буквы резкие. Направление берётся из положения света и перестраивается само.
- **Комнаты:** тёмная и светлая. Неосвещённая стена светлой комнаты выходит ровно #C7CBD6.
- **Выразительность:** 0% — калибровка по кадрам гайда «Свечение. Направления» и рефам арт-директора (`docs/references/ad-*`); 100% — тот же свет ярче и объёмнее, с сильным ореолом. Между ними — плавный переход.
- **Мягкие лучи:** структура света с неровным шагом, расплывается к концу луча.
- **Живой свет.** С лучами живут сами лучи — каждый раскрывается и прикрывается в своём темпе, по ним идёт дымка, без лучей свет медленно и неровно играет яркостью, а дымка чуть густеет и редеет. Источник и настройки света стоят. Скорость и длина петли — ползунками, плеер — в той же карточке (пробел). Видео — покадрово в MP4 (WebCodecs) с размытием движения и бесшовной петлёй.
- **Форматы:** 16:9, 9:16, 1:1, 4:5. При смене формата свет остаётся на том же месте относительно краёв.
- **Экспорт:** PNG/JPG до 4096 px отдельным проходом в полном разрешении, копирование PNG в буфер для вставки в Figma; три слоя (фон, свет, объём) — каждый копируется или скачивается отдельно; свет и объём на прозрачном: точно складываются в Plus lighter, а в тёмной комнате ложатся и в Normal. ZIP включает точный цельный PNG с зерном для сравнения.
- **Настройки экспорта:** замок пропорций включён по умолчанию, размер и формат запоминаются между открытиями. Предпросмотр 100% показывает готовый файл и его фактический вес; качество JPG — от 40% до 100%.
- **JSON-пресет:** сохранение, открытие, перетаскивание на окно. Пресеты прототипа с 58 ключами переносятся в новую модель автоматически.
- **Работа без потерь:** отмена/повтор на 80 шагов, автосохранение в браузере.

## Проверки

```sh
npm run check            # ESLint, TypeScript, сборка, unit-тесты
npx playwright install chromium
npm run test:e2e         # реальный WebGL: редактор, экспорт, импорт, мобильная вёрстка
```

WebGL в e2e считается на процессоре: на Mac — SwiftShader, весь набор идёт 2–3 минуты. CI на GitHub (`.github/workflows/ci.yml`) ставит Mesa lavapipe (`mesa-vulkan-drivers`): SwiftShader на раннере собран с медленным Subzero и не успевает за экспортом и видео. Какой WebGL достался браузеру, тесты пишут в лог первой строкой; на CI без lavapipe прогон останавливается сразу.

## Калибровка света

`tools/sheet.html` рендерит набор Look в один контактный лист рядом с эталонами. `tools/shoot.mjs` снимает его в PNG с аппаратным GPU — так проверяются правки шейдера и профилей:

```sh
npm run dev
node tools/shoot.mjs '{"cell":[589,310],"cols":2,"refs":["/docs/references/ad-setup-top.png"],"looks":[{"angle":0,"tone":"blue"}]}' sheet.png
```

Каждому Look в листе можно передать `mode` (`light`, `haze`, `base`), чтобы снять слой отдельно. Рефы арт-директора лежат в `docs/references/ad-*`.

## Развёртывание

Для команды VK: https://vk-light.demo.pragmatica.design — сервер демок Pragmatica в Москве (pgcode), вход по паролю: логин `demo`, пароль выдаёт выкладка. Сервер забирает сборку из приватной копии `pragmatica-design/demo-vk-light`. Выложить то, что сейчас в `main` на GitHub:

```sh
tools/ship-demo.sh
```

Скрипт отправляет `main` в копию, собирает и выкладывает её через pgcode и ждёт, пока сервер подхватит. Пароль держится между выкладками; сменить — `tools/ship-demo.sh --password <новый>`. Демку, которую не обновляли 90 дней, сервер снимает — выкладывать хотя бы раз в три месяца. Нужны `gh auth login` в рабочем GitHub (участник `pragmatica-design`) и `npm ci`.

Ещё одна копия: https://photon-light.vercel.app — Vercel, настройки в `vercel.json` (сборка Vite, заголовки безопасности и кеширование ассетов). Каждый пуш в `main` выкатывается сам.

```sh
npm run build   # содержимое dist/ — на любой статический HTTPS-хостинг
docker build -t photon-studio . && docker run --rm -p 8080:8080 photon-studio
```

`deploy/nginx.conf` — gzip, CSP и кеширование хешированных ассетов.

## Приложение для macOS и Windows

`desktop/` — та же студия в окне приложения (Electron, движок Chromium: свет считается так же, как в Chrome). Сборка сайта лежит внутри и отдаётся по адресу `photon://app`, сцена хранится в приложении. Под macOS окно без заголовка: кнопки окна в плашке сцены, системное меню на русском, ⌘O/⌘S/⌘E/⌘Z из меню, системные окна открытия и сохранения.

```sh
npm --prefix desktop install   # один раз
npm run desktop                # запустить из исходников
npm run desktop:pack           # desktop/out: Photon-<версия>-mac.dmg и Photon-<версия>-windows-setup.exe
```

DMG — одно приложение для Apple Silicon и Intel, подписано локально (ad-hoc). Установщик Windows ставит приложение в один клик для текущего пользователя, без прав администратора. Оба собираются на Mac. Без подписи Developer ID (macOS) и сертификата (Windows) система при первом запуске предупреждает; как открыть — на лендинге. Иконка — плотный круг света в дымке; `python3 desktop/icon/make.py` пересобирает её для macOS, Windows и лендинга (нужны numpy и Pillow).

## Лендинг

`landing/` — страница с двумя установщиками, статика без сборки. `npm run landing` кладёт свежие установщики из `desktop/out` в `landing/downloads/`; дальше папку `landing/` можно выложить на любой хостинг. Размер файлов страница берёт из ответа сервера, кнопка своей системы — главная.

## Устройство

```text
src/
  domain/      модель Look, бренды, сцена из Look, тон-кривая, история
  engine/      WebGL2: сцена (light.frag), накопление, bloom, ACES, экспорт
  components/  холст, инспектор, миниатюра источника, экспорт
  hooks/       состояние Look с историей и автосохранением
tools/         контактный лист для калибровки, выкладка на сервер демок
docs/          архитектура, гайд из Figma, эталоны
```

Подробнее — [архитектура](docs/architecture.md), [выпуск](docs/release.md).
